About

Aspen uses the Bootstrap framework so there are many classes and layouts we have access to when we create basic or custom pages in Aspen. Because Aspen uses a basic WYSIWYG editor, if you want to add Bootstrap elements to a page, you have to go to the code view and hand-code things like buttons or badges or to use the Bootstrap column configurations or other Bootstrap elements.

On some of the training pages we are creating for Next Search Catalog we wanted to be able to add some content in collapsible panels. To make these panels consistent and easy to use for a variety of NEKLS staff members, I created this simple fill-in web form that allows staff to fill in the panel title and the panel content, then click a button that outputs a consistently constructed Bootstrap panel.

This entire project is available on Github and released with an MIT license, so if you'd like to see the source code or if you'd like to download a copy of the project and change it to suit your needs, feel free to do so.
